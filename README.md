# Висновок:

Під час виконання лабораторної роботи було успішно спроектовано, реалізовано та протестовано алгоритми сортування злиттям (ітеративна та рекурсивна версії) та алгоритм швидкого сортування за схемою Хоара. Аналіз кількості базових операцій (Таблиця 3.1) для масиву з 9 елементів показав, що рекурсивна версія сортування злиттям виявилася найефективнішою за кількістю порівнянь (18) та присвоювань (37), проте вона потребує додаткових витрат пам'яті на стек через 17 рекурсивних викликів. Ітеративний підхід до злиття дозволив повністю уникнути рекурсії, але ціною значного збільшення кількості операцій присвоювання (111).   Швидке сортування за схемою Хоара виконало найбільшу кількість порівнянь (64) та 98 присвоювань при тих самих 17 рекурсивних викликах. Це пояснюється специфікою пошуку порушень відносно опорного елемента (яким завжди обирався перший елемент підмасиву) у циклах під час розбиття. Побудовані графи трасування наочно довели принцип роботи парадигми «розділяй і володарюй» та практично підтвердили логарифмічну часову складність O(n log n) для досліджених алгоритмів.
